# Third-Party Notices

## Hugging Face Models

The application downloads and runs the following third-party models. Model weights are not included in this repository and remain subject to their original terms.

- [MoritzLaurer/mDeBERTa-v3-base-mnli-xnli](https://huggingface.co/MoritzLaurer/mDeBERTa-v3-base-mnli-xnli)
- [uer/roberta-base-finetuned-jd-binary-chinese](https://huggingface.co/uer/roberta-base-finetuned-jd-binary-chinese)
- [distilbert-base-uncased-finetuned-sst-2-english](https://huggingface.co/distilbert-base-uncased-finetuned-sst-2-english)

The Hugging Face cache defaults to `~/.cache/huggingface` and can be relocated with `HF_HOME`.

## Python Packages
